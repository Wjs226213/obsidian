## 一、点位取点方式

### 1. P1‑P28（基准为镭射头绝对高度）

取点逻辑：
- **Y 坐标**：Trend Edge 工具取 PIN 的 Y 向边缘，+0.23mm 偏移得到 Y 中心
- **X 坐标**：斑点工具取 X 坐标，无偏移
- **最终测量点位**：(斑点X, Trend Edge Y + 0.23mm)
- P15‑P28 取点逻辑与 P1‑P14 相同

**处理方式**
分别使用两个斑点工具对目标区域分别进行高度抽取得到

### 2. E1‑E6

取点逻辑：
- **Y 坐标**：斑点工具取 Y 坐标，无偏移
- **X 坐标**：边缘工具取 X 向边缘 + 偏移量
- **各点 X 偏移**：
  - E1 and E4： +0.76mm  
  - E2 and E5：+1.04mm
  - E3 and E6：+0.76mm
  - 

### 3. S1‑S3

取点逻辑：
- **X 坐标**：边缘工具取 X 向边缘 + 偏移
  - S1：+0.76mm
  - S2：+1.04mm
  - S3：+0.76mm
- **Y 坐标**：边缘工具取 Y 向边缘 + 0.1mm（SOP 未标注，规避边缘干扰）

### 4. 9 个焊脚

取点逻辑：
- 直接通过斑点工具获取 XY 坐标，无额外偏移

## 二、高度 & 平面度测量逻辑

### 1. 37PIN 平面度

| 项目 | 说明 |
|------|------|
| **基准** | 镭射原始高度拟合虚拟基准平面 |
| **测量对象** | P1‑P37 共 37 个点 |
| **判定方式** | 各点到基准平面的偏差值 → 平面度 |

### 2. 铁壳面 — 37PIN 高度

| 项目       | 说明             |
| -------- | -------------- |
| **基准**   | 铁壳面原始高度拟合平面    |
| **测量对象** | P1‑P37 共 37 个点 |
| **判定方式** | 各点到铁壳面基准的高度差   |

### 3. 9 焊脚高度

| 项目       | 说明                       |
| -------- | ------------------------ |
| **基准**   | 37PIN 虚拟面（同 37PIN 平面度基准） |
| **测量对象** | 9 个焊脚                    |
| **判定方式** | 各焊脚到 37PIN 基准面的高度差       |

### 4. 9 焊脚平面度

| 项目 | 说明 |
|------|------|
| **基准** | 37PIN 虚拟面 + 焊脚实测高度，整体向下补偿 −0.496mm，合计 46 点（37PIN + 9焊脚）重新拟合平面 |
| **测量对象** | 9 个焊脚 |
| **判定方式** | 各焊脚到新拟合基准面的偏差值 → 平面度 |

## 三、流程配置概要

```
开始
 │
 ├─ 拍摄（LJ-V7020，灰度 + 高度双输出）
 │
 ├─ 检测单元
 │   ├─ Trend Edge → 取 PIN Y 向边缘
 │   ├─ 斑点工具 → 取 X/Y 坐标
 │   ├─ 边缘工具 → 取 X/Y 向边缘
 │   └─ 偏移计算 → 数值计算单元
 │
 ├─ 数值计算
 │   ├─ 坐标偏移修正
 │   ├─ 高度值读取
 │   └─ 平面度拟合计算
 │
 ├─ 判定
 │   ├─ 37PIN 平面度判定
 │   ├─ 铁壳面-37PIN 高度判定
 │   ├─ 9 焊脚高度判定
 │   └─ 9 焊脚平面度判定
 │
 └─ 输出（OK/NG 判定结果）
```
## 具体要做什么

### 任务一：取点坐标计算（数值计算单元）

在流程中配置检测单元后，用数值计算单元把各工具输出的原始坐标换算成最终测量点位。

| 点位 | X 来源 | X 偏移 | Y 来源 | Y 偏移 | 数量 |
|------|--------|--------|--------|--------|------|
| P1‑P28 | 斑点工具 | 无 | Trend Edge Y 向边缘 | +0.23mm | 28 |
| E1‑E6 | 边缘工具 X 向边缘 | E1/E3/E6: +0.76mm，E2/E5: +1.04mm | 斑点工具 | 无 | 6 |
| S1‑S3 | 边缘工具 X 向边缘 | S1/S3: +0.76mm，S2: +1.04mm | 边缘工具 Y 向边缘 | +0.1mm | 3 |
| 9焊脚 | 斑点工具 | 无 | 斑点工具 | 无 | 9 |

**合计 46 个测量点**（28 + 6 + 3 + 9）

### 任务二：37PIN 平面度

- **输入**：P1‑P37 共 37 个点的镭射原始高度值
- **基准**：37 个点的高度值拟合一个虚拟基准平面
- **计算**：每个点到基准平面的偏差（最大值 − 最小值 = 平面度）
- **判定**：平面度 ≤ 公差 → OK，否则 NG

### 任务三：铁壳面 — 37PIN 高度

- **输入**：P1‑P37 共 37 个点的高度值
- **基准**：铁壳面原始高度拟合平面
- **计算**：每个点到铁壳面基准的高度差
- **判定**：各点高度差在公差范围内 → OK，否则 NG

### 任务四：9 焊脚高度

- **输入**：9 个焊脚的高度值
- **基准**：37PIN 虚拟面（同任务二的基准）
- **计算**：每个焊脚到 37PIN 基准面的高度差
- **判定**：高度差在公差范围内 → OK，否则 NG

### 任务五：9 焊脚平面度

- **输入**：37PIN 高度值 + 9 焊脚实测高度值，共 46 个点
- **补偿**：焊脚整体向下补偿 −0.496mm
- **基准**：补偿后的 46 个点重新拟合基准平面
- **计算**：9 个焊脚到新基准平面的偏差
- **判定**：平面度 ≤ 公差 → OK，否则 NG
