## 你在 XG-X 上每天该干什么（精简版）

### 调试时：用数据代替手感

|别人做的|你该做的|
|---|---|
|调完看一张图 OK 就过|连续跑 200 次，导出结果 CSV，算 **均值/3σ/CPK**​|
|匹配分数低就拉灵敏度|画**分数分布直方图**，看是整体偏移（标定问题）还是长尾散（光学/振动）|
|精度飘了凭经验猜原因|把曝光/光源电流/温度/分数一起回归，找**哪个变量在偷偷劣化**​|
|模板框大一点"保险"|模板**只留目标部位轮廓**，背景多 10% 匹配掉一截|

**具体操作**：XG-X 的 **VisionDatabase**​ 打开，每次触发自动存结果+图像。调试完拉 CSV 回电脑，pandas 三行代码出报告：

```

# 3σ > 客户公差的 1/5 → 还得调
```

### 抓目标部位：XG-X 上的标准三段式（照抄就行）

```
流程图顺序：触发 → 预处理 → 粗定位 → 精定位 → 标定输出
```

**① 粗定位（速度）**

- 处理单元：**ShapeTrax3**，动作模式=`高速`
    
- 搜索范围：**只框目标可能晃的最大框**，别全 FOV
    
- 关亚像素 → 这一级只求"在哪儿"
    

**② 精定位（精度）**

- 用粗定位的 XY 做 **ROI 跟随**（位置偏移修正 ON）
    
- 同一目标换 **Trend Edge**​ 或开 `高精度/亚像素 ON`
    
- Trend Edge 扫 5000 个 edge point 做最佳拟合 → 比单点亚像素抗脏污
    

**③ 输出**

- Alignment 单元：像素→mm
    
- Robot Vision 接口直接出 ΔX/ΔY/Δθ 给机器人
    

**速度不够时只动这一件事**：把搜索范围从全 FOV 缩到粗定位容差框。比改算法立竿见影。

**精度飘时先看这一件事**：连续 200 次结果的 3σ。均值偏=标定/手眼矩阵歪；3σ 散=光学或振动。两件事修法完全不同，别混着调。

### 你比别人多做的"一个模块"

在流程图末尾加一个 **Statistics Unit（脚本/C函数）**：

- 每 100 件算一次 3σ
    
- 超门限 → 自动报警 / 降速重拍 / 触发重新标定
    

这个模块**不用每次都跑**，但交付给客户时打开，你出的报告就是：_"连续 1000 件，重复定位 3σ=0.018px，CPK=2.1"_ —— 这比"我调过了没问题"值钱十倍。
