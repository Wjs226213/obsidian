## 🟢 第一阶段：变量与基础概念（Day 1）

- [x] **掌握 5 种变量类型及作用域**

| 符号  | 类型   | 作用域    | 口诀         |
| :-: | ---- | ------ | ---------- |
| `@` | 临时变量 | 当前计算窗口 | **临时用完就扔** |
| `#` | 局部变量 | 当前程序内  | **本程序专用**  |
| `$` | 全局变量 | 整个控制器  | **所有程序共享** |
| `%` | 系统变量 | 系统自带   | **只读不改**   |
| `&` | 图像变量 | 图像数据   | **存图像用的**  |
|     |      |        |            |

> [!tip] 区分技巧
> 变量前缀就是"作用域标签"。`#` 是你最常用的，`$` 用于跨程序传值。

- [x] **理解入出力区分**（输入 / 输出 / 处理 / 控制 / 存储）
- [x] **理解数据类型**（数值 / 坐标 / 布尔 / 图像 / 字符串）

## 🟡 第二阶段：基础函数（Day 2-3）

### 2.1 基本运算函数

- [x] `Abs()` — 取绝对值
- [x] `Ave()` — 取平均值
- [x] `Max()` / `Min()` — 取最大 / 最小值
- [x] `Max2()` / `Min2()` — 取阵列中的最大 / 最小值
- [x] `ANS` — 计算单元结果值
- [x] `Cos()` / `Sin()` — 三角函数  暂时不用看

> [!example] 示例速记
> ```
> #a = Abs(#b - #c)      ← 差的绝对值
> #a = Ave(#b, #c, #d)   ← 三个数取平均
> #a = Max(#b, #c, #d)   ← 三个数取最大
> #a - Max2(4,#a[])      ← 系列的数值中取得最大
> ```

### 2.2 逻辑函数

- [ ] `AND` — 逻辑积（全部满足才为真）
- [x] `OR` — 逻辑或（满足一个就为真）
- [x] `NOT(P)` — 取反（P>0 时为 0，否则为 1）
- [ ] `Lt(P0, P1)` — P0 < P1 时为 1
- [ ] `Eq(P0, P1)` — P0 = P1 时为 1

> [!tip] AND vs OR 速记
> **AND** = 严师（全部过关才算过）
> **OR** = 宽师（一个过关就算过）

- [ ] `Dist(Q1, Q2)` — 两点间距离
>[!tip]  MidXY使用

### 3.2 直线相关

- [ ] `Line(Q1, Q2)` — 两点形成直线
- [ ] `Linels(N, Q[], P)` — 多点阵列描述直线
- [ ] `LnAngle(L)` — 直线的角度（±90°）
- [ ] `LnDist(L, Q)` — 点到直线的距离
- [ ] `LnDistXY(L, Q)` — 点到直线的垂足点

### 3.3 圆与交点

- [ ] `Circle3(Q1, Q2, Q3)` — 三点描述圆
- [ ] `Circlels(N, Q[], P)` — 多点阵列描述圆
- [ ] `Isect(L1, L2)` — 两直线的交点

### 3.4 角度

- [ ] `Angle(Q1, Q2)` — 两点形成的角度
- [ ] `LLAngle(#LINE1, #LINE2)` — 两直线夹角（0°~180°）

> [!example] 几何计算核心组合
> ```
> #直线 = Line(Q1, Q2)           ← 先造直线
> #交点 = ISect(#line1, #line2)   ← 再求交点
> #距离 = LnDist(#Line1, Q1)      ← 点到线距离
> #垂足 = LnDistXY(#Line1, Q1)    ← 点到线垂足
> ```

## 🔴 第四阶段：流程控制语句（Day 6）

### 4.1 IF 判断

- [ ] 基本 IF-ELSE 结构
- [ ] 多重条件 ELSE IF

```
IF #C_r > #lower AND #C_r < #upper THEN
    #JG = 0          ← OK
ELSE
    #JG = 1          ← NG
END IF
```

### 4.2 FOR 循环

- [ ] 基本 FOR-NEXT 结构
- [ ] 循环中读取结果数组

```
FOR @A = 0 TO 3
    #bandian[@A] = !U[0005].RSLT.XY[@A]:AB
NEXT
```

### 4.3 多重条件

```
IF @B = 3 THEN
    @B = 1
ELSE IF @A = 1 THEN
    @A = 10
ELSE IF @A = 2 THEN
    @A = 100
END IF
```

> [!warning] 常见错误
> - FOR 循环的 `@` 临时变量在循环外不可用
> - IF 判断条件里 AND/OR 优先级：**AND 优先于 OR**

## 🔵 第五阶段：相机与光学（Day 7）

### 5.1 转换比率速记

| 像素 | 1倍光学 | 0.5倍光学 |
|:---:|:---:|:---:|
| 30万 | 0.0074 mm/px | 0.0148 mm/px |
| 100万 | 0.0074 mm/px | 0.0148 mm/px |
| 200万 | 0.0044 mm/px | 0.0088 mm/px |
| 500万 | 0.00345 mm/px | 0.0069 mm/px |

- [ ] 记住：**像素越高，单像素代表的实际尺寸越小**（精度越高）
- [ ] 记住：**光学倍率减半，mm/px 翻倍**

### 5.2 光学公式

- [ ] `PMAG = SS / FOV` — 镜头放大倍数
- [ ] `f = WD × PMAG / (1 + PMAG)` — 焦距计算
- [ ] `LE = PMAG × f` — 镜头像平面扩充距离

### 5.3 术语表

| 缩写 | 含义 | 一句话理解 |
|:---:|------|:---|
| WD | 工作距离 | 相机到工件的距离 |
| FOV | 视野 | 相机能"看到"多大范围 |
| DOV | 景深 | 能看清的前后深度范围 |
| PMAG | 放大倍数 | 镜头把物体放大了多少倍 |
| f | 焦距 | 镜头的"度数" |

> [!tip] 景深口诀
> **大光圈 → 小景深**（背景虚化）
> **小光圈 → 大景深**（全部清晰）
