### 光学公式

| 公式 | 说明 |
|------|------|
| PMAG = SS(mm) / FOV(mm) = Hi / Ho | 镜头放大倍数 |
| 镜头焦距 f = WD × PMAG / (1 + PMAG) | 焦距计算 |
| LE = Di - f = PMAG × f | 镜头像平面扩充距离 |

### 术语表

| 缩写 | 全称 | 说明 |
|:---:|------|------|
| WD | Work Distance | 物距/工作距离 |
| FOV | Field of View | 视场/视野 |
| DOV | Depth of Field | 景深 |
| Ho | - | 视野的高度 |
| Hi | - | 摄像机有效成像面的高度 |
| PMAG | - | 镜头的放大倍数 |
| f | - | 镜头的焦距 |
| LE | - | 镜头像平面的扩充距离 |
| SS | Sensor Size | CCD感光面积 |
| Di | - | 后焦面距离 |

### 景深说明
- **大光圈** → 小景深
- **小光圈** → 大景深

## 七、常用公式及语句汇总

### 几何计算

| 公式 | 说明 |
|------|------|
| `#直线变量 = Line(Q1, Q2)` | 两点形成直线 |
| `#位置变量 = ISect(#line1, #line2)` | 两条直线交点 |
| `#位置变量 = LnDistXY(#Line1, Q1)` | 点到直线的垂足 |
| `#纯量 = LnDist(#Line1, Q1)` | 点到直线距离 |
| `#位置 = I4XY(Q1, Q2, Q3, Q4)` | 四个点的中心位置（顺逆时针） |
| `#JX_JD = I4Line(#直线1, #直线2, #直线3, #直线4)` | 顺逆时针 |
| `#Dist = Dist(Q1, Q2)` | 两点间距离 |
| `#位置 = MidXY(Q1, Q2)` | 两点的中点 |
| `#angle = LLAngle(#LINE1, #LINE2)` | 两条直线夹角（0° ~ 180°） |
| `#纯量 = LnAngle(#line1)` | 直线角度（±90°） |

### 统计计算

| 公式 | 说明 |
|------|------|
| `#纯量 = Max(#纯量1, #纯量2)` | 最大值 |
| `#纯量 = Max2(N, Q[])` | 阵列中的最大值（N：个数，Q[]：位置阵列） |
| `@B = MaxN(#Dist[0], #Dist[1], ...)` | 最大值指数 |
| `@B = MaxN2(N, #Dist[])` | 最大值指数（N：个数） |
| `@B = MinN(#Dist[0], #Dist[1], ...)` | 最小值指数 |
| `@B = MinN2(N, #Dist[])` | 最小值指数（N：个数） |
