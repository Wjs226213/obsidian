# Git 冲突解决报告

> 日期：2026-08-02  
> 分支：main

---

## 一、冲突概要

| 项目       | 详情                                               |
| -------- | ------------------------------------------------ |
| **冲突文件** | `.obsidian/workspace.json`                       |
| **冲突原因** | 本地分支与远程分支 diverged（本地 2 commits vs 远程 8 commits） |
| **冲突类型** | `UD` — 远程删除该文件，本地修改了该文件                          |
| **解决方式** | 保留本地版本（`git checkout --ours`）                    |

---

## 二、冲突原因分析

1. **本地** 有 2 个未推送的 commit（Obsidian Git 自动备份产生）
2. **远程** 有 8 个新 commit（另一台设备同步上去的）
3. 两边都修改了 `workspace.json`，远程端删除了该文件，本地端保留了它
4. 执行 `git pull` 时触发合并冲突

`workspace.json` 是 Obsidian 的临时工作区状态文件，记录当前打开的标签页、面板布局等，不影响笔记内容。

---

## 三、解决步骤

```bash
# 1. 查看冲突文件
git diff --name-only --diff-filter=U
# 输出：.obsidian/workspace.json

# 2. 保留本地版本（workspace.json 是临时状态文件，保留本地即可）
git checkout --ours .obsidian/workspace.json

# 3. 将解决后的文件加入暂存区
git add .obsidian/workspace.json

# 4. 删除自动生成的冲突报告文件
rm -f conflict-files-obsidian-git.md

# 5. 提交合并结果
git commit -m "resolve merge conflict: keep local workspace.json"
```

## 四、后续建议

| 建议                               | 说明                     |
| -------------------------------- | ---------------------- |
| `.gitignore` 排除 `workspace.json` | 该文件频繁变动且不影响内容，排除后可避免冲突 |
| 同步前先 `git pull`                  | 每次在新设备操作前拉取最新版本        |
| 同步后及时 `git push`                 | 改完后推送到远程，保持两端一致        |

### 建议添加到 `.gitignore` 的内容

```
.obsidian/workspace.json
.obsidian/workspace-mobile.json
```
