  1. 问题定义 — 确定任务类型（图像分类 / 目标检测 / 语义分割 / 实例分割 /
  图像生成等）
  2. 数据收集 — 图像数据集（公开数据集如 ImageNet、COCO，或自建数据集）
  3. 数据标注 — 打标签（分类标签、 bounding box、mask
  等），常用工具：LabelImg、CVAT、Labelme
  4. 数据预处理
    - 图像缩放/裁剪到统一尺寸
    - 归一化（像素值缩放到 0~1 或标准化）
    - 数据增强（翻转、旋转、缩放、颜色抖动、Cutout、Mixup、Mosaic 等）
  5. 数据划分 — 训练集 / 验证集 / 测试集
  6. 选择模型架构 — 根据任务选择：
    - 分类：ResNet、EfficientNet、ViT
    - 检测：YOLO 系列、Faster R-CNN、DETR
    - 分割：U-Net、Mask R-CNN、DeepLab
  7. 选择预训练模型 — 迁移学习，用 ImageNet
  等预训练权重做初始化（非常关键，能大幅加速收敛）

  训练中

  8. 搭建训练环境 — GPU 驱动、CUDA、深度学习框架（PyTorch / TensorFlow）
  9. 设置超参数 — 学习率、batch size、epoch
  数、优化器（SGD/Adam）、学习率调度策略
  10. 模型训练 — 前向传播 → 计算损失 → 反向传播 → 更新权重
  11. 验证与调参 — 监控验证集 loss，早停（Early Stopping），超参数搜索

  训练后

  12. 模型评估 — 测试集指标：
    - 分类：Accuracy、Precision、Recall、F1、混淆矩阵
    - 检测：mAP、IoU
    - 分割：mIoU、Dice Coefficient
  13. 模型优化
    - 处理过拟合（数据增强、Dropout、正则化）
    - 模型压缩（剪枝、蒸馏、量化）
  14. 模型部署
