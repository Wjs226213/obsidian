## 02 申请步骤：逐字段拆解

申请入口： **[https://100t.xiaomimimo.com](https://link.zhihu.com/?target=https%3A//100t.xiaomimimo.com/)**

打开页面，点击「立即申请」，进入表单。表单共 5 个字段，每一个都影响审核结果和最终额度。

![](https://pic4.zhimg.com/v2-c891583064588e933cb561c623cc1dc1_1440w.jpg)

**字段一：邮箱**

填写前先确认一件事：这个邮箱必须和你在 [platform.xiaomimimo.com](https://link.zhihu.com/?target=http%3A//platform.xiaomimimo.com) 注册的账号邮箱一致。很多人翻车在这里——用手机号注册平台却没绑邮箱，额度到账了收不到通知，或者两个邮箱不一致直接被判无效。

操作路径：去 [account.xiaomi.com](https://link.zhihu.com/?target=http%3A//account.xiaomi.com) → 安全设置 → 绑定邮箱，确认绑定完成后再回来填表。

![](https://picx.zhimg.com/v2-7c7149b451deefd14b6e3eee642bb127_1440w.jpg)

**字段二：常用 AI 开发 / Agent 工具**

复选框，选项包括 OpenClaw、Claude Code、Codex、 [Hermes](https://zhida.zhihu.com/search?content_id=274015865&content_type=Article&match_order=1&q=Hermes&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODU5NDEzNTQsInEiOiJIZXJtZXMiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzQwMTU4NjUsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.X3NE3weTYl1EboNBaeJPToWtU8UD8IGckMhudHOMD7U&zhida_source=entity) Agent、OpenCode、KiloCode、Cursor、Windsurf、Aider、Cline 等。如实勾选你在用的工具，不要全选。审核方会拿这里的选项和后面的项目描述对照，前后不一致反而降低通过率。

**字段三：主要使用的底层模型系列**

选项涵盖 Claude、Gemini、GPT、MiMo、DeepSeek、豆包、MiniMax 等系列。如实选，选多个也没问题。这个字段本身权重不大，关键在下一个。

**字段四：项目描述（决定额度档位的核心字段）**

这是整张表最重要的地方。审核方根据这里的内容决定通过与否，以及分配哪个档位的额度。官方给出的参考方向是： [工程复杂度](https://zhida.zhihu.com/search?content_id=274015865&content_type=Article&match_order=1&q=%E5%B7%A5%E7%A8%8B%E5%A4%8D%E6%9D%82%E5%BA%A6&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODU5NDEzNTQsInEiOiLlt6XnqIvlpI3mnYLluqYiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzQwMTU4NjUsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.kAS3kQxAsJOzl5bqsH3K9X-50bh8UMYVd1bGpS6XKDw&zhida_source=entity) 、核心代码场景、具体工程量或数据，以及可量化的效果证明。

**字段五：使用证明与影响力证明**

支持上传文件（JPG / PNG / GIF / PDF / DOC，最多 5 个，单文件不超过 2048KB），也可以填写 GitHub 项目链接、视频链接或产品演示地址。

## 03 拿到额度后怎么用

去平台申请 [API Key](https://zhida.zhihu.com/search?content_id=274015865&content_type=Article&match_order=1&q=API+Key&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODU5NDEzNTQsInEiOiJBUEkgS2V5IiwiemhpZGFfc291cmNlIjoiZW50aXR5IiwiY29udGVudF9pZCI6Mjc0MDE1ODY1LCJjb250ZW50X3R5cGUiOiJBcnRpY2xlIiwibWF0Y2hfb3JkZXIiOjEsInpkX3Rva2VuIjpudWxsfQ.JBDETJvnYqkssbJyguDUcONBQdw3m6A6zzLOkw1ifqw&zhida_source=entity) ： **[https://platform.xiaomimimo.com](https://link.zhihu.com/?target=https%3A//platform.xiaomimimo.com/)**

然后把 MiMo 配置进你的工具。平台文档里有各个工具的接入教程，包括 Claude Code、Cursor、OpenCode、Hermes Agent、Cline 等，搜「工具总览」直接找对应的配置文档： [Xiaomi MiMo API 开放平台 Token Plan 全球上线](https://link.zhihu.com/?target=https%3A//platform.xiaomimimo.com/docs/zh-CN/integration/tools-overview)

以 Hermes 为例，配置步骤如下：

1. [hermes](https://zhida.zhihu.com/search?content_id=274015865&content_type=Article&match_order=1&q=hermes&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODU5NDEzNTQsInEiOiJoZXJtZXMiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzQwMTU4NjUsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.UmcvJank0n-QKVFIkW1cGcBfU-ARk4g934xjqEVTAo8&zhida_source=entity) model 选择 Xiaomi MiMo
2. 输入 API Key
3. Base URL 按需二选一：赠送 Token Plan 用 `https://token-plan-cn.xiaomimimo.com/v1` ，赠送余额用 `https://api.xiaomimimo.com/v1`
4. 选择一个 MiMo 模型即可
